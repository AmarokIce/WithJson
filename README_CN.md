**相较于 V1 有什么特别的吗？**

就像是[预期得那样](https://github.com/AmarokIce/WithJson/issues/5)，V2 带来了更多更好的改动！这是 V2 中值得关注的特色的部分内容：
- 更规范的定义格式：统一使用全部小写模式处理，完整使用 AJ4J 取代 Gson。
- 更好的记忆体利用率：不再使用数据类预处理 Json 的内容，而是直接对 Json 文本处理。
- 自动从服务端同步数据：正在频繁更新吗？让玩家们自动从连接的服务器获取 OVO-Packet 吧！
- 更好的接口：是开发者吗？现在我们有更好的接口来为 OVO 添加新的注册项！

**我该如何从 V1 迁移到 V2？**

转换工具正在积极开发中！但我们现在有一个生成工具能给帮助你快速入门。
